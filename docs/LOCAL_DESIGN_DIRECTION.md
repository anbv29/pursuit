# Pursuit local design direction

This revision is local only. It does not change the hosted application.

## Reference trail

- Designeer Inspiration: https://designeer.xyz/inspiration
- Its Minimal Gallery listing: https://designeer.xyz/inspiration/minimal-gallery
- Minimal Gallery SaaS collection: https://minimal.gallery/tag/saas/
- Folk listing and live site: https://minimal.gallery/folk/ and https://www.folk.app/
- Parallel listing and live site: https://minimal.gallery/parallel-web-systems/ and https://parallel.ai/
- 21st.dev Card Tabs by uiable: https://21st.dev/@uiable/components/card-tabs
- Also reviewed 21st.dev cards/navigation catalogues and Geist Context Card.

Designeer was inspected in the connected browser because the web fetcher could
not access it. The catalogue lists inspiration galleries rather than only
individual SaaS sites. Folk and Parallel were shortlisted through Minimal Gallery.

## Chosen direction

Folk is the primary reference for approachable product presentation, generous
space and clear typography. Parallel informs the presentation of research as
structured information. Neither site's branding, copy, layout or assets is copied.
21st.dev's tabbed-card pattern informs progressive disclosure in the brief.
The Context Card tooltip was reviewed but was less suitable for core content.
No component source was copied and no new component dependency was installed.

The installed ui-ux-pro-max skill guided accessibility, keyboard interaction,
reserved dimensions and responsive layout. Impeccable was not used.

## Implementation

- Warm paper canvas, charcoal type and restrained copper accents; paired dark theme.
- Plus Jakarta Sans titles, Manrope controls, Source Sans 3 report text.
- Original report artifact with customer, competition and next-test tabs.
- Each illustrative finding includes evidence to seek, a limitation and an action.
- Existing accessible tab keyboard handling and stable panel dimensions.
- Glass navigation, subtle atmosphere and reduced-motion behavior retained.
- Divided process rows and a unified pricing comparison surface.
- Prices still come from the backend catalogue; session-aware actions remain wired.
- No provider model names added to product copy.

Verification is recorded in aboutme.txt after execution; this document is not a
claim that every test or production release has passed.
