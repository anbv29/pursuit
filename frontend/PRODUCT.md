# Pursuit

Pursuit helps founders research a product's market, compare evidence, plan a go-to-market strategy, and run measurable customer experiments. The workspace is an operating tool. A founder should see what needs attention, inspect the source behind a claim, and choose the next action without navigating unrelated controls.

Primary surfaces are the dashboard, company reports, GTM strategy, experiments, approvals, priorities, and Fo assistant. Authentication, onboarding, shared reports, and settings use the same typography and controls. Demo content remains explicitly labelled. Suggested plans and hypotheses must never look like measured outcomes.

The October 2026 redesign is frontend-only. Existing requests, permissions, authentication, stored report content, and backend code remain unchanged from the merged GTM release.

## Visual direction

The November 2026 update softens the earlier dashboard direction with warm off-white panels, a pale stone canvas, muted sage actions, soft charcoal text, rounded rectangular controls, and a clearly grouped sidebar. Keep the compact Inter typography and existing workspace composition. Dark mode uses green-gray surfaces and desaturated accents. Apply the shared visual language to marketing, authentication, onboarding, reports, experiments, and supporting pages.

The quality bar is a useful, compact workspace with real information visible at desktop and phone sizes, readable control boundaries, keyboard focus, and no horizontal page overflow. Phone experiment rows expose stage and verdict together. Desktop supporting content follows the table without waiting for the taller secondary column.
